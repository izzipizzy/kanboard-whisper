# Telegram Whisper для Kanboard

Голосовое в Telegram → исходная расшифровка Whisper → при желании переписать через DeepSeek → сохранить задачу в Kanboard.

Плагин работает с текстовыми сообщениями, голосовыми и аудио. Нормализация через DeepSeek напрямую или через OpenRouter — по желанию. Без ключа распознавание работает локально, заголовок берётся из начала текста.

## Установка в Docker / OrbStack

Требуется Kanboard 1.2.54+, SQLite, Docker Compose и Python 3 на компьютере. Контейнер Kanboard должен иметь постоянные тома `data` и `plugins`.

```sh
./scripts/install-local.sh ИМЯ_КОНТЕЙНЕРА_KANBOARD
```

Скрипт устанавливает PHP-плагин и запускает два сервиса: Whisper и обработчик Telegram. Модель `medium` скачивается автоматически при первом запуске и сохраняется в Docker volume. Публичный IP, HTTPS и webhook не нужны. Установка только ZIP из каталога Kanboard добавляет интерфейс плагина; сервисы распознавания и бота нужно установить отдельно из этого репозитория.

Администратор открывает **Настройки → Telegram Whisper → Доступ пользователей к плагину** и отмечает нужные учётные записи. Администраторы имеют доступ автоматически.

Каждый разрешённый пользователь открывает **Мой профиль → Telegram Whisper** и настраивает своё подключение:

1. Создайте бота у `@BotFather` командой `/newbot` и вставьте токен.
2. Введите свой числовой Telegram ID (можно узнать у `@userinfobot`). Можно несколько ID через запятую. Пустой список никого не допускает.
3. Выберите проект по умолчанию, категорию и колонку. Видны только проекты, где ваша учётная запись может создавать задачи. Под типом задачи используется категория Kanboard — например «Идея», «Баг», «Задача». Их можно заранее создать в настройках проекта.
4. Включите бота и сохраните настройки.
5. Напишите боту `/start`, отправьте голосовое или текст. Проверьте расшифровку. Под ней три кнопки: «Отмена», «Переписать через DeepSeek», «Сохранить». DeepSeek запускается только по кнопке и показывает обновлённый черновик; задача создаётся после «Сохранить».
6. Если нужна нормализация — выберите DeepSeek/OpenRouter, добавьте ключ и сохраните. Появится список моделей: выберите нужную и сохраните ещё раз. Кнопка «Сохранить и обновить модели» заново загружает актуальный каталог. Для OpenRouter показаны модели DeepSeek; ID можно указать и вручную. При сбое API текущий черновик останется без изменений. Исходная расшифровка остаётся и в нормализованных задачах.

Для ссылок на задачи заполните URL приложения в общих настройках Kanboard. Локальный адрес будет открываться на телефоне только при доступе к домашней сети/VPN. Получать голосовые бот может и когда вы в дороге.

## Как пользоваться

- `/projects` — список доступных проектов и выбор кнопкой.
- `/swimlanes` — список активных дорожек выбранного проекта.
- `/type` — выбрать категорию.
- Смена проекта или дорожки обновляет текущий черновик; старые кнопки подтверждения перестают действовать. Черновик и ответ после создания показывают проект, дорожку, колонку и категорию.
- `/status` — посмотреть проект и режим обработки.
- `/cancel` — отменить черновик.
- Новое голосовое или текст заменяет предыдущий черновик. Его срок хранения — 24 часа.
- Лимит записи — 10 минут / 20 МБ. Обработка последовательная.
- У каждой учётной записи свои токен бота, Telegram ID, API-ключ и проект по умолчанию. Один бот не может принадлежать двум учётным записям. Задачи создаются от имени владельца подключения, с проверкой его прав в Kanboard. Выбранные в Telegram проект и дорожка сохраняются отдельно для каждого отправителя.
- Задача всегда создаётся только после «Сохранить». Автосохранение отключено. При ошибке DeepSeek черновик не меняется. Повторное переписывание использует исходную расшифровку.

По умолчанию используется многоязычная модель `medium`, лимит памяти сервиса — 5 ГБ. Настройки `WHISPER_MODEL` и `WHISPER_MEMORY_LIMIT` можно переопределить в `.env.local`. Большая модель требует больше времени и памяти.

Кнопка переписывания занимает отдельный ряд; «Отмена» и «Сохранить» находятся ниже. Во время обработки бот показывает «Переписываю через DeepSeek… Подождите.», затем обновляет сообщение результатом.

## Обслуживание

```sh
docker compose --env-file .env.local ps
docker compose --env-file .env.local logs --tail=50
./scripts/update-local.sh ИМЯ_КОНТЕЙНЕРА_KANBOARD
# Остановка
docker compose --env-file .env.local down
```

Ключи каждого пользователя хранятся отдельно в базе Kanboard, черновики — в `data/whisper`. Текст отправляется провайдеру только по кнопке «Переписать через DeepSeek», аудио распознаётся локально. Защитите резервные копии базы. Не публикуйте порт сервиса Whisper в интернет.

Интерфейс, инструкция и бот поддерживают русский и английский. Язык берётся из профиля Kanboard, а если он не задан — из общих настроек приложения. Язык распознавания речи задаётся отдельно. Полные технические ограничения и варианты развёртывания: [README](../README.md). Подготовка публикации: [RELEASING](RELEASING.md).

## Личный промпт

В личных настройках можно изменить **Промпт DeepSeek / OpenRouter** (до 8000 символов). Кнопка **Сохранить со стандартным промптом** возвращает исходные инструкции. Промпт отдельный для каждого пользователя и применяется с обоими провайдерами только по кнопке переписывания. Формат JSON с полями `title` и `description` бот добавляет автоматически, расшифровку передаёт отдельно.

## Обновление и ограничения

Поддерживаемая установка: SQLite и Docker Compose. Подключения и доступ теперь хранятся в таблице плагина с удалением вместе с пользователем. Настройки из ранней версии мигрируют один раз. При обновлении установщик сохраняет согласованную копию БД в `.backups/`; она содержит ключи, не публикуйте её. Отзыв доступа выключает бота: повторная выдача доступа не запускает его автоматически.

Общий обработчик рассчитан на небольшую доверенную команду: длинное аудио задерживает другие подключения. Лимиты на подключение: 12 попыток распознавания и 30 переписываний в час, максимум 5 переписываний одного черновика, включая неудачные попытки. Это не изоляция ресурсов между недоверенными пользователями. Whisper останавливает декодирование после десяти минут и отказывает при занятом обработчике; повторите позже. Ошибка доставки Telegram повторяется максимум три раза, постоянный отказ пропускается сразу. После ручного обновления PHP-файлов перезапустите контейнер бота.

Администраторы и обладатели резервных копий БД имеют доступ к сохранённым ключам. Подробнее — [SECURITY.md](../SECURITY.md).
